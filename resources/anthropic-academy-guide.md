# YouTube Resource Guide: Anthropic Academy — Free AI Courses

**Video:** [Anthropic Built You a FREE AI Degree (I Reviewed All 18 Courses)](https://youtu.be/q4k3OVq_XXU)

## Overview

The video reviews **Anthropic Academy**, a free training platform from Anthropic
(the makers of Claude) offering structured, self-paced courses on AI and the
Claude ecosystem. Highlights covered in the video:

- 18 structured courses, 300+ lessons, 25+ hours of video
- Almost every course awards a shareable certificate of completion
- No Claude subscription or credit card required — sign up with just an email
- Hosted on Skilljar at [anthropic.skilljar.com](https://anthropic.skilljar.com/)
- Discovery hub at [anthropic.com/learn](https://www.anthropic.com/learn)

## Course Catalog

### Foundational (no coding required)
- **Claude 101** — using Claude for everyday work tasks and core features
- **Claude Code 101** — using Claude Code in a daily development workflow
- **Introduction to Claude Cowork** — the Cowork task loop, plugins, skills, and file/research workflows
- **AI Capabilities and Limitations** — how generative models work, real capabilities and boundaries

### Developer-focused
- **Building with the Claude API** — authentication, streaming, tool use, prompt caching, extended thinking
- **Introduction to Model Context Protocol (MCP)** — building MCP servers/clients from scratch in Python; tools, resources, and prompts
- **Model Context Protocol: Advanced Topics** — sampling, notifications, filesystem access, transport mechanisms
- **Introduction to Agent Skills** — building, configuring, and sharing reusable Skills in Claude Code

### Cloud platform integrations
- **Claude with Amazon Bedrock**
- **Claude with Google Cloud Vertex AI**

### AI Fluency tracks
- **AI Fluency for Educators**
- **AI Fluency for Students**
- **AI Fluency for Nonprofits**
